**Образовательный самоучитель для изучения ислама, Корана, дуа, азкаров, основ веры и семейных отношений.** С уважением к разным традициям и строгим разграничением первоисточника, комментария, перевода и редакционного пояснения.

## Русский и таджикский языки

Первая версия переключателя **Русский / Тоҷикӣ** сохраняет выбранный язык на устройстве. Переведены основные элементы интерфейса и [страница «О проекте» на таджикском](about-tg.html); подготовлены [все восемнадцать историй на таджикском](stories-tg.html) из существующих 18. Страница о проекте и истории имеют отдельные статические адреса на двух языках.

**Важное ограничение:** подготовлены редакционные таджикские переводы смысла и краткого контекста всех 43 карточек дуа/азкаров, а также значений, пояснений, оснований и личных мольб всех 99 карточек имён Аллаха. Русские транскрипции, подробные пояснения к дуа и многие отдельные учебные HTML-страницы пока не локализованы. При выборе таджикского непереведённый материал необходимо явно отличать от переведённого. Арабские первоисточники не переводим автоматически и не изменяем. Для переведённых таджикских материалов требуется независимая проверка литературного языка и религиозного смысла. Рабочие таблицы сверки: [первая партия](docs/tajik-stories-source-review-2026-11-23.md), [вторая партия](docs/tajik-stories-batch2-review-2026-11-24.md), [третья партия](docs/tajik-stories-batch3-review-2026-11-24.md), [четвёртая партия](docs/tajik-stories-batch4-review-2026-11-24.md), [пятая партия](docs/tajik-stories-batch5-review-2026-11-24.md), [заключительная партия](docs/tajik-stories-batch6-review-2026-11-24.md).

Для новой тройки — [сверка аятов и ограничения пересказа](docs/russian-stories-batch-4-source-review-2026-11-23.md).
- **Пилот аудиочтения 18 историй:** «Слушать историю» и «Слушать показанные истории», пауза, продолжение, остановка, предпочтение предположительно мужского русского голоса, низкий тембр, спокойная скорость, предварительное прослушивание и подсветка фрагмента. Используется Web Speech API. Арабские аяты не озвучиваются. Web Speech API не сообщает пол голоса: выбор мужского основан на названии, а итоговый тембр, качество и работа без интернета зависят от устройства.
- **Подготавливаемая и проверяемая офлайн-версия:** 41 локальный ресурс с SHA-256; установка, обновление и чтение страниц без сети проверяются в Chromium на каждом PR. Доступность новой версии на опубликованном Cloudflare Worker требуется подтверждать отдельно. Внешние страницы религиозных источников не кешируются.
- Автоматическая проверка ссылок и структуры, мобильного/компьютерного отображения, сборки, офлайн-режима и опубликованного сайта.

## Запуск исходников

```bash
python3 -m http.server 8765 --bind 127.0.0.1
# Открыть http://127.0.0.1:8765/
```

Проверяемая сборка офлайн-релиза:

```bash
python3 tool/prepare_website.py --check-root
python3 tool/prepare_website.py --build build/website
```

**Важно:** после любого изменения включённых в офлайн-версию файлов нужно обновить хеши командой `python3 tool/prepare_website.py --write-root` и проверить их через `--check-root`. Не выдавайте обычную локальную папку за проверенную опубликованную версию.

## Достоверность и пределы проверки

Технические тесты и редакционные сверки **не равны независимой богословской экспертизе**. В текущем каталоге 12 из 43 карточек дуа/азкаров имеют статус `source_checked`, 31 — `draft`; экспертный статус не установлен ни для одной. Отдельно остаётся независимая проверка семейного курса, произношения и транскрипций.

Никогда не проставляйте `expert_checked` без документированного заключения компетентного специалиста. Если источник или толкование спорные, укажите разницу взглядов и пределы вывода.

**Следующий этап:** конкретные уточнения в [issues #18, #17, #15](https://github.com/NaFaS-Bek/talab-al-haqq/issues), ручная проверка PWA на реальных телефонах, аудит внешних ссылок, доступности и производительности. Приоритеты и критерии завершения — в [сводном отчёте](docs/consolidated-project-audit-roadmap-2026-11-23.md).

Текст Корана и лицензия: см. [TANZIL-LICENSE.txt](TANZIL-LICENSE.txt). Автоматическое аудиочтение пока включено только на странице историй; для других разделов — будущая задача. Голосовой движок может требовать интернет даже при офлайн-доступности текстов.
