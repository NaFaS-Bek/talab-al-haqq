# Этап 4 — посимвольная сверка текстов и транскрипций

Дата: 2026-11-21. Основание: `docs/source-audit-2026-11.md`, `docs/adhkar-source-review-2026-11.md`, `docs/final-source-review-round-2.md`.

## Границы этапа

Предыдущий редакционный обход охватил 43/43 карточек по источникам, границам цитат и контексту. **Это не подтверждение фонетической или богословской достоверности 43 карточек.** Этот этап должен проверять отдельно арабский текст, огласовки, русскую транскрипцию и перевод каждого элемента, включая вложенные `repetitionRule.stages` и сегменты.

## Первый приоритет — конкретное известное замечание

- ID: `h_muslim_2692`.
- Источник: https://sunnah.com/muslim:2692
- В предыдущем отчёте зафиксировано, что отображаемая транскрипция заканчивается `ва би-хамдих`, а пояснение отдельно указывает `би-хамдихи` при чтении без остановки.
- Проверить поле `transliterationRu`, транскрипции сегментов, `transliterationNoteRu` и UI; сделать явным вариант **без остановки** (`би-хамдихи`) и отметить вариант **с остановкой** (`би-хамдих`) — только после сверки с арабской огласовкой и утверждения единого правила обозначения пауз.
- Не менять автоматически другие окончания `-хи` на основании одной карточки.

## Рабочий протокол для каждой карточки

1. Записать ID, название, точную ссылку на редакцию первоисточника, дату сверки и границы цитаты.
2. Посимвольно сравнить `arabicText` с первоисточником: порядок слов, диакритику, отсутствие пропусков и добавлений. Варианты чтения/риваята хранить раздельно.
3. Сверить `transliterationRu` с тем же арабским текстом, включая правила конечных гласных, остановки, удвоения и долготы. Проверить вложенные сегменты.
4. Сверить `translationRu` по смыслу с оригиналом; указывать переводчика либо редакционную атрибуцию и ограничения.
5. Сверить число/порядок повторений с конкретным источником. Отличать предписание повторить слова от описания действия рассказчиком.
6. Для хадисов явно атрибутировать оценки конкретным учёным/редакциям и не подменять их собственной оценкой достоверности.
7. Завести запись «старое → новое», мотивировку, ссылку и итоговый статус; при сомнении оставить `draft`.

## Технические критерии готовности

- Автотест фиксирует структуру и целостность 43 карточек, полноту обязательных полей, валидность ссылок и соответствие повторений указанным стадиям; тест **не объявляет текст религиозно достоверным**.
- Для всех обнаруженных расхождений есть прозрачный отчёт с ID, старым и новым текстом и источником.
- Интерфейс различает «дуа», «наставление», «отрывок аята», «полная сура»; для наставления нет вводящей в заблуждение кнопки «Читать дуа».
- Статус `source_checked` не показывается пользователю как «экспертно подтверждено».
- Изменения готовятся отдельным PR с тестами, без автоматического слияния в `main`.
