# Ручная сверка утренних и вечерних азкаров — проход 1

Дата: 2026-11-21. Сверены точные страницы источников с записями `data/content.json` на момент аудита. Это текстовая сверка, не фетва и не независимая экспертиза чтения.

## 1. `h_muslim_2692` — Сахих Муслим 2692
Источник: https://sunnah.com/muslim:2692

- **Подтверждено источником:** формула `سُبْحَانَ اللَّهِ وَبِحَمْدِهِ`; утром и вечером по 100 раз. Число `repetitionRule.stages[0].count = 100` согласуется с текстом.
- **Найдено расхождение в отображении:** основная транскрипция и транскрипция сегмента оканчиваются на «ва би-хамдих.», а `transliterationNoteRu` объясняет два варианта: «би-хамдих» при остановке и «би-хамдихи» при продолжении. Арабское `بِحَمْدِهِ` содержит конечную огласовку `هِ`; поэтому чтение без остановки нужно явно показывать, а не прятать только в примечании.
- **Рекомендация редактору:** показать в основной строке вариант с конечным «и» и отдельно сохранить пояснение об остановке, либо явно подписать основной вариант «при остановке». Не заменять автоматически без согласования единообразного стандарта транскрипции.
- **Статус:** транскрипция требует редакционной корректировки; `draft` оставить.
