# Пилот аудиочтения 15 историй · 2026-11-23

## Реализовано
- Кнопка «Слушать историю» в каждой из пятнадцати карточек.
- «Слушать показанные истории» работает с фильтрами.
- Web Speech API для русскоязычного текста, управление паузой/продолжением/остановкой, голосом и скоростью 0,8–1,4×.
- Подсветка активного фрагмента и сообщения о статусе.
- В аудиотекст входят **только** русские заголовки, редакционный пересказ и нравственные уроки. Не читаются меню, метаданные, источники и закрытые вопросы.
- Арабские письменные фрагменты исключены из TTS. **Это не чтение Корана и не сертифицированное произношение**.
- Чтение запускается только нажатием пользователя. Скорость сохраняется локально, если хранилище доступно.

## Ограничения
- Русский голос, работа без интернета, фоновой режим и заблокированный экран зависят от браузера и устройства. Гарантии нет.
- Офлайн-PWA сохраняет JavaScript и страницы, но системный TTS может требовать интернет. Наш код не вызывает платный TTS API, хотя голосовой движок ОС может быть сетевым.
- Тесты Playwright используют контролируемый имитатор синтезатора: они проверяют очередь, кнопки и текст, а **не реальный звук на телефоне**.
- Для арабских текстов впоследствии нужны лицензированные, проверенные записи с указанием чтеца/источника.
- Следующий этап — ручные испытания на реальных Android/iOS, затем масштабирование на остальные учебные страницы.
