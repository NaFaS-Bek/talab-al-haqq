# Проверка первоисточников пяти азкаров — 21.11.2026

## Метод и ограничения

Проверены опубликованные арабские тексты на указанных страницах Sunnah.com. Это **сверка первоисточников**, а не полный построчный аудит актуального `data/content.json`: большой JSON не удалось получить целиком через доступный интерфейс GitHub в рамках данного прохода. Поэтому выводы ниже не следует понимать как подтверждение фактической транскрипции всех полей в текущей ветке. Регрессионные тесты добавлены, но их запуск в этой сессии **не подтверждён**.

## Важные редакционные детали

- `بِحَمْدِهِ` содержит конечную огласовку «и» при продолжении; при остановке конечный краткий гласный не произносится. Отдельно помечать этот случай; не считать паузальную форму ошибочной самой по себе.
- У ат-Тирмизи 3391 указаны две атрибуции оценки: автор в арабском тексте называет хадис `حسن`; англоязычная таблица приводит `Sahih (Darussalam)`. Не сливать эти оценки в собственное утверждение сайта.
- Автотесты лишь защищают заранее установленные фрагменты от регрессий. Они не проверяют точность всех диакритических знаков, русскую фонетику каждого слова, смысловую полноту переводов и различия риваятов.
- При первом полноценном доступе к `data/content.json` запустить `node tests/content-audit.cjs` и `node tests/adhkar-source-regressions.cjs`; зафиксировать результаты в PR, затем сравнить каждую запись посимвольно.
