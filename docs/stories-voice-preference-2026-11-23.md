# Настройка голосового режима · 2026-11-23

Пользователь сообщил: базовый TTS звучал слишком высоким, женским и роботизированным.

- По умолчанию: более низкий тембр (pitch 0.82) и умеренный темп (rate 0.85), доступен режим «Очень низкий».
- Автоматический выбор приоритетно ищет **русские голоса, название которых похоже на мужское** (например Pavel, Dmitry, Alexander). В Web Speech API нет надёжного поля gender. При отсутствии подходящего названия пользователю выводится честное предупреждение; голос не называют достоверно мужским.
- Выбор голоса и тембра можно менять вручную. Кнопка «Проверить голос» позволяет услышать короткую оригинальную нейтральную фразу; пример прерывает чтение текущей истории, чтобы избежать одновременной речи.
- Не имитируются голоса конкретных чтецов Корана. Тексты арабского Корана не синтезируются.
- Предпочтения скорости, тембра и голоса сохраняются только в локальном хранилище при доступности. На других устройствах набор голосов может отличаться.
- Для действительно выразительной, натуральной мужской озвучки позднее потребуется отдельный качественный TTS-движок или предварительно записанное русское аудио с указанием лицензии и источника.
- Автоматические тесты проверяют выбор из мужского/женского голосов, темп, pitch и preview с **имитацией** движка, а не реальную акустику Android/iOS.

Ручная проверка качества голоса на телефоне остаётся обязательной.
