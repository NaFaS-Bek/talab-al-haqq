## Важные ограничения

- В этом проходе **не менялись** `data/content.json`, исходные арабские цитаты, русские транскрипции, переводы, `reviewStatus`, времена, повторения или служебные пояснения в `app.js`.
- Все шесть открытых опубликованных хадисов сопоставлены с уже закреплёнными арабскими выдержками и контекстом в `tests/adhkar-hadith-final-13.cjs`. Новая проверка удерживает контекстные границы, тексты и учебные сегменты.
- **Регрессионный тест не доказывает точность данных**, поскольку может закреплять и ошибку. Для каждого арабского знака/огласовки, русского звука и перевода требуется отдельная построчная независимая сверка; для звучания — квалифицированный преподаватель. Нельзя автоматически ставить `expert_checked`.
- Метки времени для 5088 и 3391 в текущем учебном интерфейсе нужно оценивать отдельно. Ни отсутствие `timingRule`, ни название карточки не разрешают самостоятельно создавать новое религиозное предписание.
- Исходные сведения о хадисах открывались по приведённым URL 23.11.2026. Если редакции источников изменятся, требуется повторная проверка.
