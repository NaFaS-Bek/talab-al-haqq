# Коранические дуа: посимвольная сверка Unicode, пакет 1 (22.11.2026)

## Объём и точный источник сравнения

Проверены четыре **полных аята** из `data/content.json` в текущей версии `main`:
- `q_17_24` — [17:24](https://quran.com/17/24);
- `q_2_250` — [2:250](https://quran.com/2/250);
- `q_27_19` — [27:19](https://quran.com/27/19);
- `q_7_23` — [7:23](https://quran.com/7/23).

Для **посимвольного Unicode-сопоставления** использована отдельно полученная копия Tanzil Uthmani 1.1 из [репозитория-зеркала acfatah/tanzil](https://github.com/acfatah/tanzil/blob/main/data/quran-uthmani.txt), исходный blob SHA `f2f03c415ea50f8493d2058ec67a90257333abe3`. Четыре неизменённые строки зеркала и оригинальное уведомление Tanzil помещены в `tests/fixtures/tanzil-uthmani-1.1-four-duas.txt`. Лицензия и официальные сведения: [Tanzil Download](https://tanzil.net/download/), [Tanzil Text License](https://tanzil.net/docs/Text_License).

**Ограничение независимости:** это воспроизводимый снимок **стороннего зеркала**, а не прямая сверка скачанного сегодня оригинального файла с серверов Tanzil. Для окончательной внешней аттестации нужно отдельно сверить снимок с официальной загрузкой и подтвердить выбранные параметры экспорта (в частности, татвиль). Иные способы отображения на Quran.com не считаются сами по себе ошибкой в варианте Tanzil.

## Результаты точного сравнения

При посимвольном сравнении без нормализации получены различия:

| Аят / ID | Сравнение с зеркалом без изменений | Единственное различие | После удаления **только** U+0640 в снимке |
| --- | --- | --- | --- |
| 17:24 / `q_17_24` | совпадает | нет | совпадает |
| 2:250 / `q_2_250` | не совпадает | 1 знак U+0640 | совпадает |
| 27:19 / `q_27_19` | не совпадает | 2 знака U+0640 | совпадает |
| 7:23 / `q_7_23` | не совпадает | 1 знак U+0640 | совпадает |

U+0640 — **татвиль** (визуальный знак растяжки `ـ`), в этой редакции зеркала он встречается непосредственно перед верхним малым алифом (`ـٰ`), например в `ٱلْكَـٰفِرِينَ` против `ٱلْكَٰفِرِينَ`. **Ни одна огласовка, буква, маленький алиф или знак остановки при сравнении не удалялись.** После удаления только татвиля строки побуквенно совпали; это установлено на уровне Unicode-кодовых точек с данным снимком. Строки сайта не переписывались.

В `tests/adhkar-quran-unicode-batch1.cjs` закреплена воспроизводимая сверка четырёх стихов с этим снимком. Тест дополнительно следит за `fullVerseArabic`, сегментами, ссылками на аяты и за тем, чтобы машина не присвоила `expert_checked`.

## Русская транскрипция — что просмотрено, но **не аттестовано**

Четыре `transliterationRu` заполнены, текст единственного сегмента каждой карточки совпадает с транскрипцией родительской записи. Это **не** доказывает точность произношения. Перед корректировками требуется проверка с носителем/преподавателем чтения:

| ID | Точки внимания при фонетической проверке |
| --- | --- |
| `q_17_24` | `ٱخْفِضْ` (ض), `ٱلذُّلِّ` (ذ), `صَغِيرًا` (ص, غ); граница повествования `وَقُل` и слова мольбы `رَّبِّ` |
| `q_2_250` | `وَثَبِّتْ` (ث), `ٱنصُرْنَا` (ص), `ٱلْكَٰفِرِينَ` (долгая гласная); обычное произношение и остановка |
| `q_27_19` | `ضَاحِكًا` (ض, ح), `تَرْضَىٰهُ` (ض), `صَٰلِحًا` (ص, ح); несколько долгих гласных и знак хамзы |
| `q_7_23` | `ظَلَمْنَآ` (ظ), `تَغْفِرْ` (غ), слитное чтение `وَإِن لَّمْ` и паузы |

Эти особенности — **темы для проверки**, а не автоматически доказанные ошибки транскрипции. Упрощённая русская запись по своей природе не передаёт арабские звуки полностью. Изменять её по догадке, особенно для текста Корана, нельзя.

## Что изменено и что остаётся

Добавлены только документ, источник-снимок и автоматическая проверка в CI; **ни одна из 43 карточек, арабский текст, перевод или транскрипция не изменялись**. Тест не подтверждает качество таджвида, правила остановок, передачу всех русских звуков, корректность конкретного перевода или наличие независимой религиозной экспертизы.
