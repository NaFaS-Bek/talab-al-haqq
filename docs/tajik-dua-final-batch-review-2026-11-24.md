# Завершение редакционного перевода каталога дуа

12 карточек: Муслим 2202, Бухари 6369, 3282, 5743, Муслим 918b, 2725a; Коран 17:24, 2:250 и суры 1,103,108,109 (19 аятов). Сопоставлены с арабским текстом каталога, Sunnah.com и Quran.com. Самостоятельные черновые переводы смысла, не цитаты из опубликованного таджикского перевода. Не проводилось независимое сопоставление всех формулировок с таджикскими тафсирами. Для 2202 сохранены отдельные этапы 3 и 7, без изменения счётчиков; дуа не заменяет медицинскую помощь. Для 2:250 сохранён исторический контекст, не инструкция к насилию. Для 17:24 отделена вводная часть. Все 43 исходные карточки покрыты, 7 коротких сур содержат 34 поаятных перевода; ещё 8 сегментов в трёх коранических карточках пророков. data/content.json, арабский текст, ссылки, русская транскрипция, исходные статусы и числа повторения не изменены. Независимые богословская, языковая и фонетическая проверки остаются необходимыми. Новые CI-проверки не подтверждены.
