# Коран: политика экспорта Tanzil и отображения знаков вакфа/васла

Дата: 22 ноября 2026. Область действия: 22 карточки Корана (15 дуа и 7 коротких сур). Изменения арабского текста этим документом не разрешаются.

## 1. Типы доказательств

**Официальные правила:** [Tanzil Download](https://tanzil.net/download/), [Pause Marks](https://tanzil.net/docs/pause_marks), [релиз 1.1](https://tanzil.net/updates/), [лицензия](https://tanzil.net/docs/Text_License). Эти страницы описывают доступные настройки и значения символов, но не удостоверяют ранее полученный нами файл.

**Два сторонних снимка:** контрольные 16 аятов из acfatah/tanzil (blob SHA f2f03c415ea50f8493d2058ec67a90257333abe3; tests/fixtures/tanzil-uthmani-1.1-remaining-duas.txt) и отдельная выборка 54 аятов из iptvchecker/content-tanzil (tests/fixtures/tanzil-uthmani-1.1-quran-sample-54.json). Предыдущие тесты связали эти 54 аята с 22 карточками сайта, учитывая отдельно документированное отображение басмалы в 6 коротких сурах. **Сторонние зеркала не являются официальными издателями.**

**Независимая официальная выгрузка: проведена 22.11.2026 в GitHub Actions.** [Протокол прямого скачивания и сравнения 54 аятов](https://github.com/NaFaS-Bek/talab-al-haqq/actions/runs/45051863184). Из официального домена получен полный файл с 6236 аятами, заголовком Tanzil Uthmani 1.1 и SHA-256 **bf4f57b968d03f4131c070b1e285da9be0e0a108a21c910e872801ca273312c8**. Все **54 контрольных аята** из выборки iptvchecker совпали с прямой выгрузкой **посимвольно (54/54)**. Из 16 строк снимка acfatah **7 совпали дословно**, **9 совпали только после исключения четырёх явно указанных кодовых точек U+0640/U+06D6/U+06DA/U+06DE**. Неразрешённых текстовых расхождений в этих двух выборках не осталось. Сам полный файл в репозиторий не добавлялся; SHA-256 и результаты сохранены в отчёте GitHub Actions. Это **не** полная независимая сверка каждого из 6236 аятов с другим издателем и не аудиоаттестация.

**Устное чтение:** никакое совпадение цифровых символов не подтверждает произношение, вакф, васл, риваят или правильность таджвида. Необходима отдельная проверка преподавателем.

## 2. Точные параметры воспроизводимого запроса

POST с application/x-www-form-urlencoded на https://tanzil.net/pub/download/index.php:

| Поле | Значение | Назначение |
| --- | --- | --- |
| quranType | uthmani | Тип арабской записи |
| outType | txt-2 | Строки с номерами аятов |
| marks | true | Включать знаки остановки |
| sajdah | true | Включать знаки саджда |
| rub | true | Включать рубʿ аль-хизба ۞ |
| tatweel | true | Включать татвиль при малых алифах |
| agree | true | Принять условия лицензии |

С этими **переданными параметрами** официальный сервер отдал файл с указанным выше SHA-256. Это не доказывает, что **историческое зеркало acfatah** получило текст с теми же настройками: в нём сохранены дополнительные знаки по сравнению с официальным ответом по нашей выборке. Сам факт отправки параметра не заменяет побайтовое сравнение ответа. Если сервер изменит ответ или будет недоступен, скрипт отразит это отдельным статусом, а не назовёт другое зеркало официальным источником.

## 3. Политика значений знаков

По [официальной документации Tanzil](https://tanzil.net/docs/pause_marks):

| Unicode | Обозначение | Объяснение |
| --- | --- | --- |
| ۘ U+06D8 | م | Обязательная остановка |
| ۙ U+06D9 | لا | Недопустимая остановка |
| ۚ U+06DA | ج | Можно остановиться или продолжить |
| ۗ U+06D7 | قلى | Предпочтительнее остановиться |
| ۖ U+06D6 | صلى | Предпочтительнее продолжить |
| ۛ U+06DB | ∴ ∴ | Выбрать остановку на одном из двух парных знаков |

۞ U+06DE — отметка рубʿ аль-хизба, **не знак остановки**. ـ U+0640 — татвиль, **не знак дополнительной паузы**.

## 4. Решение для текущего сайта

Сохраняем неизменёнными все арабские аяты, огласовки, русские транскрипции, переводы, счётчики, источники и статусы экспертной проверки. Не вставляем, не скрываем и не переставляем Unicode-символы автоматически.

В пяти дуа (14:40–41, 2:127–128, 12:101, 7:89 и 5:114) уже зафиксированы десять различий с третьесторонним снимком: 6 × ۚ и 4 × ۖ. О них читателю сообщают **отдельные свёрнутые справочные блоки**, не вставляя символы внутрь Корана. Это не указание делать паузу в конкретном месте.

Общий словарь шести знаков находится в разделе сайта «Источники и проверка». Там отдельно указано: **54/54 проверяемых строк соответствуют прямой официальной выгрузке**, но происхождение настроек более раннего зеркала и экспертная трактовка остановок остаются незавершёнными.

## 5. Условия перехода на полноценное отображение знаков внутри арабского текста

1. **Для контрольной выборки выполнено:** получен прямой официальный ответ с версией, датой, SHA-256 и параметрами запроса. Перед любым новым изменением арабской строки повторно подтверждать ответ и его контрольную сумму; результат должен совпадать с закреплённым SHA-256 либо требовать ручного разбирательства.
2. **Для контрольной выборки выполнено:** 54/54 строк совпали с официальным файлом *без нормализации*, шесть случаев отображения басмалы ранее зафиксированы отдельно. Продолжить независимую сверку остальных редакционных параметров зеркала; не применять удаление всех диакритик как «проверку».
3. Согласовать подход с преподавателем таджвида с указанным риваятом, включая правила парных знаков и возобновления чтения.
4. Протестировать RTL-представление на мобильных и десктопе, поиск, копирование и чтение программами экранного доступа.
5. Предложить отдельный PR «до / после» с проверяемыми источниками и отметкой реальной экспертной оценки. Не назначать expert_checked машинным тестом.

## 6. Регрессионные проверки

- tests/adhkar-quran-pause-source-comparison.cjs — сравнение 10 точных мест со сторонним закреплённым снимком.
- tests/verify-official-tanzil.py — прямой POST на издательский сервер, проверка 6236 аятов, закреплённого SHA-256 и 54 аятов плюс 16 из другого зеркала. Машинный JSON-отчёт сохраняется как отдельный артефакт GitHub Actions. При недоступности источника не имитирует успех.
- tests/browser-smoke.cjs — неизменность текста аятов и доступность справочных блоков и общего словаря.
- GitHub Actions запускает обязательные локальные проверки. Сетевую проверку источника нужно читать отдельно: зелёный локальный CI **не** означает успешную независимую проверку Tanzil.

**Статус:** независимая выгрузка Tanzil 1.1 **получена и подтверждена для всех 54 контрольных аятов (54/54 точных совпадений)**, SHA-256 закреплён. Остальные вопросы настройки более раннего зеркала, смысла остановок, выбранного риваята и экспертной проверки не закрыты. Документ **не разрешает** автоматически менять священный текст.
