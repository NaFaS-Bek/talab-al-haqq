## Выбранный способ

- Azure AI Speech с официальным TTS API: по умолчанию `ru-RU-DmitryNeural` (мужской русский голос). Возможная альтернативная проба `ru-RU-Lev:MAI-Voice-2` (HD, доступность и тариф зависят от региона/аккаунта).
- Параметры SSML: темп −9%, высота −2 полутона и пауза 650 мс между смысловыми фрагментами. Это технические настройки, **не гарантия** красивого звучания; окончательный критерий — прослушивание человеком.
- Генерируется **готовый MP3**, одинаковый на Android и ПК. Сайт не обращается к платному API при обычном чтении страницы; генерация делается отдельно и один раз.
- В аудио входят только русский заголовок, редакционный пересказ по аятам и **явно обозначенные редакционные выводы**. Не входят арабские аяты, чтение Корана, меню, вопросы со скрытыми ответами, сноски и ссылки.
- До публикации аудио надо прослушать, исправить неверные ударения/имена и убедиться, что в записи нет добавленных фактов.
- Встроенный браузерный TTS остаётся запасным вариантом. Подготовленный плеер появляется только после ручного разрешения публикации и успешной загрузки реального файла.

## Выпуск образца (локально, не в браузере)

1. `python3 tool/generate_story_audio.py --story yusuf --preview-text` — посмотреть, какой текст попадёт в запись, и подтвердить его точность.
2. Настроить собственный Azure Speech ресурс. В **локальные переменные среды**, но никогда в GitHub и чат, поместить `AZURE_SPEECH_KEY` и `AZURE_SPEECH_REGION`.
3. `python3 tool/generate_story_audio.py --story yusuf --voice ru-RU-DmitryNeural`.
4. Прослушать `audio/stories/yusuf.mp3` на телефоне и компьютере; обратить особое внимание на «Юсуф», «Аллах», корректность остановок и отсутствие механических интонаций.
5. Только после ручного одобрения записать MP3 в репозиторий и пересобрать PWA: `python3 tool/prepare_website.py --write-root`. Генератор поставляет бинарный MP3, упаковщик автоматически включает его в SHA-256-проверенный офлайн-набор.

## Границы и безопасность

- Без доступа к официальному TTS API реальный MP3 не генерируется. Не использовать неофициальный захват Edge Read Aloud как готовый публикуемый аудиоконтент: условия повторного использования не подтверждены.
- При подготовке **не** размещать ключ API в клиентском JavaScript, URL сайта, репозитории или логах.
- Для религиозного текста качество произношения и смысл важнее тембра. Тексты являются редакционными пересказами, а не дословным переводом Корана и не коранической рецитацией.
- Бесплатный тариф и право публикации надо проверять по актуальным условиям Azure; HD может тарифицироваться иначе, поэтому без подтверждённой учётной записи HD-синтез не запускать.
- Автоматические браузерные тесты не могут подтвердить субъективное качество аудио. Для него требуется живое прослушивание.
