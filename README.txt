Версия интерфейса 0.12.0 (15)

Восстановленный существующий сайт из NFS_Dua_Ready_Website.zip.
Его исходный data/content.json сохранён побайтно. Это самостоятельный
снимок каталога: 43 дуа/азкара, 99 имён, 75 учебных материалов и 27 событий.
Он не заявлен как полная копия всех новых возможностей Flutter-приложения.
Раздел «История халифов» получает общий с приложением канонический JSON.

Подготовить комплект без публикации:
  python tool/prepare_website.py
Готовая папка:
  build/website
Проверка локально:
  python -m http.server 8085 --bind 127.0.0.1 --directory build/website
Открыть http://127.0.0.1:8085/ . Для внешнего размещения нужен HTTPS.
Не открывайте index.html через file://: service worker так не работает.

При обновлении сохраняются ключи nfs_favs, nfs_counts, nfs_theme и прежние
идентификаторы материалов. Место чтения хранится дополнительно в nfs_reading.
Офлайн-копия готова только после статуса «Доступно офлайн».
На iPhone сначала добавьте сайт на главный экран, откройте новую иконку
онлайн и дождитесь готовности. Safari и установленное приложение могут
использовать разные хранилища. Очистка данных браузера удаляет сохранения.

Сведения о происхождении и проверке перенесены в «Источники и проверка»
и «Об источнике» конкретного материала. Спорные детали остаются в тексте.
Сверка источников не является экспертным одобрением содержания.
